# Отчет по лабораторной работе: Git и основы ИБ

### 1. Что такое Git
Git — это распределенная система контроля версий, которая позволяет отслеживать любые изменения в коде и документации. В любой момент может вернуться к предыдущему состоянию проекта.

### 4. Решение задачи с .gitignore
Для предотвращения попадания временных файлов и конфиденциальных данных в репозиторий я настроил файл `.gitignore`. Я добавил в него маски для папок `__pycache__/` (артефакты Python), `outputs/` (результаты работы) и, самое главное, файл `.env`, в котором могут храниться секреты. Это позволяет Git автоматически игнорировать эти файлы при выполнении `git add .`.

### 5. Инцидент с secrets.txt
* **Как нашли утечку:** С помощью команд `git log --oneline -- secrets.txt` (увидел коммит с подозрительным названием) и `git show HEAD:secrets.txt` (просмотрел содержимое файла в истории).
* **Исправление:** Я добавил `secrets.txt` в `.gitignore`, удалил его из текущего состояния репозитория командой `git rm` и зафиксировал это новым коммитом.
* **Почему "удалить файл" недостаточно:** Даже если файла нет в последней версии кода, он остается в предыдущих коммитах в истории Git. Любой, кто клонирует репозиторий, может "откатиться" назад и прочитать секрет.
* **В реальной жизни:** Необходимо выполнить **ротацию секрета** (сменить пароль/ключ), так как он считается скомпрометированным. Также следует полностью вычистить историю репозитория с помощью специальных утилит (например, BFG Repo-Cleaner или `git filter-repo`).
